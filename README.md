# Business Tracker 📊

A lightweight Android bookkeeping app built for small business owners who want a simple way to track daily finances and see monthly profit/loss — without the complexity of traditional accounting tools.

---

## The Problem

Small shop owners in India manage their finances mentally or on paper. At month end they have no clear picture of whether the business was profitable or not. Existing tools like Tally or Vyapar are too complex for a single-owner shop.

## The Solution

Business Tracker gives shop owners a dead-simple interface to:
- Record daily cash received, restock costs, and expenses
- See today's profit instantly
- View monthly P&L summary
- Track 6 months of revenue vs expenses visually

## Features

- **Product Setup** — Add your products with purchase and selling prices once during onboarding
- **Daily Entry** — Log units restocked, cash received, and daily expenses in under 2 minutes
- **Auto Calculation** — Profit = Cash Received − Expenses − Restock Cost
- **Monthly Summary** — Total revenue, expenses, restock cost, and net profit per month
- **Revenue vs Expense Chart** — 6 month bar chart to spot trends at a glance
- **Settings** — Edit product prices and add new products anytime
- **100% Offline** — No internet required. All data stored locally on device using SQLite

## How to Run

1. Clone the repository
```bash
git clone https://github.com/kunalshirsat311-pixel/business-tracker.git
cd business-tracker
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the app
```bash
flutter run
```
